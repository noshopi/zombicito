ZOMBIES ATE MY NEIGHBORS - Enhanced Edition (standalone)
=========================================================

HOW TO PLAY
  Double-click  Play.bat
  A local server window opens and the game launches in your browser.
  Keep the server window open while playing; close it to quit.

CONTROLS (keyboard)
  Move ............ Arrow keys
  Fire weapon ..... Z
  Use item ........ X
  Cycle weapon .... A / S
  Cycle item ...... Q / W
  Start / pause ... Enter
  Select .......... Shift
  Save state ...... Shift+F2   (quick save)
  Load state ...... F4         (quick load)
  USB/Bluetooth gamepads work automatically (remap under "Control Settings").

GRAPHICS
  The game runs with a 4xScaleHQ upscaling shader by default (smoothed,
  higher-definition look). To change the style, hover the bottom player bar,
  open the gear icon > Graphics Settings > Shaders:
    - 2x/4xScaleHQ ... smoothed "HD" upscale
    - CRT modes ...... aperture / easymode / geom / mattias scanline looks
    - Disabled ....... raw original pixels
  Fullscreen: rightmost icons in the player bar.

SAVES
  Save states are stored in your browser (per machine). Use the player bar
  buttons or the hotkeys above.

WHAT'S INSIDE
  rom\zamn.sfc ........ the game ROM (unmodified original)
  data\ ............... EmulatorJS + snes9x WASM core (works offline)
  serve.ps1 / Play.bat  dependency-free local web server + launcher
